Generated by `gregale mcp server capabilities --markdown`. This reference describes the built-in starters, not arbitrary hosted code. Hosting remains **preview**.

Current protocol: `2026-07-28`. Legacy protocol: `2025-11-25`. Legacy protocol compatibility uses Streamable HTTP and does not imply deprecated HTTP+SSE transport support.

All starters default to public access and disabled Tasks. Use `mcp init --auth external-oauth` to configure private access and `--tasks --name <prefix>` to scaffold a split durable stack. Browser CORS requires an exact allowed origin; preflight does not replace bearer authorization.

Catalog hashes cover advertised definitions and policy, not handler code. Application handlers must validate arguments and business-data ownership. External side effects need Task-ID idempotency because recovery can replay work. Runtime catalog mutations and default application-resource update adapters are process-local.

Portable protocol, SDK and PostgreSQL checks do not establish native Firecracker cold boot/restore or real provider/client login interoperability. Follow [release qualification](ops/mcp-release-qualification.md) for the evidence required before promoting hosting maturity. This command does not inspect release evidence.
