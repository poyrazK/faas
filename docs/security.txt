# Gregale responsible disclosure template

The live machine-readable document is served at `/.well-known/security.txt`.
It is backed by the static handler in `pkg/securitytxt` so it remains
available during control-plane incidents.

Security reports are accepted at `security@gregale.dev` or through the
GitHub Security Advisories link in the live document. Our responsible
disclosure policy acknowledges reports within 24 hours, completes triage
within 72 hours, and provides a status update every seven days until the
issue is resolved or a mitigation is published. The full policy is in
[`docs/compliance/responsible-disclosure.md`](compliance/responsible-disclosure.md).

Please include the affected surface, reproduction steps, impact, and a safe
contact channel. Do not include customer secrets or personal data in a report.
