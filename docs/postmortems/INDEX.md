# Post-mortems

Completed post-mortems are named `YYYY-MM-DD-short-name.md` and linked here in reverse chronological order. Keep the timeline in UTC and run `make test-postmortems` before opening a pull request.

No completed post-mortems are recorded yet. Do not create fictional incidents to satisfy this index; add the first real incident after closure using [`TEMPLATE.md`](TEMPLATE.md).
