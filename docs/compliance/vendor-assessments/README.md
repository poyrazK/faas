# Critical supplier workpapers and pre-onboarding candidates

The Markdown files here are public workpaper indexes, not completed
assessments. They record scope and the evidence that still needs review. A
pre-onboarding candidate is not represented as an active sub-processor or an
approved supplier. Keep
confidential reports, customer-account exports, executed contracts, and signed
decisions in the restricted evidence store; link them by opaque evidence ID and
record the covered period and reviewer here after assessment.
