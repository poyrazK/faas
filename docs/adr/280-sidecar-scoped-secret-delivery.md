# ADR-280 · Sidecar-scoped secret delivery

- **Status:** accepted
- **Date:** 2026-09-27
- **Decision:** Allow each declared sidecar to request named app secrets through its own `env_secrets` map. Resolve references in the deployment's environment scope, include their versions in wake delivery receipts, and stage plaintext only into that sidecar's instance-scoped environment file. Sidecars receive no secrets implicitly from the main workload or from other sidecars. Rotation applies through a Gregale-managed restart; sidecar in-process reload and application acknowledgement remain unsupported.
- **Why:** Database proxies, telemetry exporters, and other helper workloads often need credentials, but giving them the main workload's complete secret environment violates least privilege. A per-sidecar positive allowlist extends Gregale's secret-delivery abstraction without exposing plaintext in deployment storage, scheduler/VMM RPCs, or shared sidecar images.
- **Consequences:** The deploy API and OpenAPI contract gain `env_secrets` on sidecars. The scheduler resolves each grant against the deployment scope and records the exact staged versions. The host unseals app-secret ciphertext only at the wake boundary and stages it to the target sidecar's workload-specific env file in the instance's writable main upper. Secret runtime target inventory includes sidecar-authorized keys, with reload support disabled for deployments containing sidecars. In-process reload/ack support requires a separate workload-level protocol. This is per-workload delivery, not a hostile-workload isolation boundary; tenant isolation remains the VM boundary.
- **Rejected alternatives:** Inheriting all main-workload secrets is not least privilege; copying values into the sidecar's direct plaintext `env` field would require customers to resubmit credentials on every deployment and duplicate the secret-management lifecycle; live reload is deferred because the current reload projection and self-ack contract are app-wide and do not identify individual workloads.
