# ADR-1204 · Write restart coverage across business checkpoints

- **Status:** accepted
- **Date:** 2026-10-12
- **Decision:** Provide a three-member `http-restart-matrix` suite using existing staged in-flight restart orchestration: before durable acceptance, after persisted intent, and after commit before acknowledgement. Each scenario owns an isolated caller/provider workspace. Reuse existing suite scheduling, timeout/resource guards, continue-on-failure behavior, and combined JSON/HTML/JUnit reports.
- **Why:** A single pending-write checkpoint does not cover the distinct recovery contracts of an operation not accepted, an accepted uncommitted intent, and a committed result with an unknown acknowledgement.
- **Consequences:** The single-writer provider fixture supports bounded payload-bound gates. Before acceptance, the binding exists only in memory and no intent is persisted; later gates persist pending or confirmed records before waiting. Read-only checkpoints distinguish receipt, durable acceptance, pending, committed, and an active hold. Matching replay commits or reads the same operation before releasing the gate; conflicting payloads cannot release it. Expired uncommitted work fails closed, while already committed results can reconcile even after acknowledgement hold expiry. Cleanup explicitly cancels gates without inventing a commit. Portable SIGKILL tests inspect the physical ledger and cover every boundary. Native acceptance version 4 requires all eleven cases, including all three named checkpoints and independent API cleanup; prior nine-case verdicts do not qualify it. Managed replacement remains distinct from process kill and can fail under draining policies.
- **Rejected alternatives:** An arbitrary sleep cannot establish a business interruption point. Automatically restarting the provider would destroy its example VM disk rather than exercise caller reconciliation against surviving storage. New campaign API endpoints or CLI scheduling flags would duplicate the existing suite and restart contracts.
