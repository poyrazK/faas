# ADR-459: Observed customer exposure for route changes

- **Status:** accepted for initial implementation
- **Date:** 2026-10-03
- **Decision:** Add a read-only, account/app/deployment-scoped route customer
  usage API over existing request telemetry, and compose it into preview route
  reports. Count weighted observed requests and distinct consumers/tenants before
  output caps. No telemetry ingestion, billing, deployment or policy writes change.
- **Identity:** Validate consumer ownership within the app/account and tenant
  ownership within the account. Preserve request-time tenant attribution;
  current membership cannot reconstruct historical identity. Revocation does not
  remove historical observations. Names, external references and credentials are
  excluded. Shared CLI reports omit identity details unless explicitly requested.
- **Coverage:** Always report observed_only. Anonymous and unresolved requests,
  retention clamping, route caps and omitted customer request volumes stay
  explicit. Missing observations cannot prove non-use. Usage does not establish
  which clients will break, and consumer/tenant counts overlap.
- **Bounds:** At most 200 route/method observations and 20 identity groups per
  route, with deterministic ordering. Existing request telemetry plan gates,
  scopes and retention apply. Retention is anchored to current read time, even
  for historical window ends. All SQL is generated by sqlc.
- **CLI:** JSON version 5 carries customer evidence in captured routes and review
  priorities. Exact method/path labels alone join. Unbound, ambiguous or capped
  evidence stays explicit. Counts are advisory and never weaken existing release
  gates; optional --customer-details includes bounded IDs for follow-up.
- **Acceptance:** PostgreSQL tests cover weighted counts, immutable deployment,
  account/app isolation, historical tenant links, revoked identities, anonymous
  traffic, detail caps and ordering. HTTP/CLI/SDK tests cover scope, window,
  availability, output redaction and preservation of coverage metadata.
