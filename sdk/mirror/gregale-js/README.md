# Gregale JavaScript SDKs

JavaScript and TypeScript packages for [Gregale](https://gregale.dev).

| Package | Directory | Description |
|---|---|---|
| `@gregale/sdk-node` | [packages/sdk-node](packages/sdk-node) | Gregale API client, workflows, realtime, operations and runtime helpers for Node.js |

The packages are not on npm yet. [Install the SDKs](https://gregale.dev/docs/sdks#node)
shows how to build and install one from this repository.
