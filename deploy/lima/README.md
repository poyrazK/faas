# Retired local virtualization harness

The local nested-virtualization harness in this directory is retired and is
not a supported development or acceptance environment. Its scripts and image
definitions remain only so historical changes can be inspected; do not use
them for production validation or release evidence.

The supported metal path is the dedicated native x86_64 Linux KVM acceptance
pair. See [`docs/ops/native-m9-acceptance.md`](../../docs/ops/native-m9-acceptance.md)
and the repository workflow in [`CLAUDE.md`](../../CLAUDE.md) for the current
pre-flight and acceptance commands.
